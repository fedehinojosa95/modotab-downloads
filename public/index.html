Descargar para Windows

Windows 10 y 11 · no pide contraseña de administrador
  1. Toca el botón azul de arriba. Se empieza a bajar un archivo llamado ModoTab POS Setup.
  2. Cuando termine de bajar, ábrelo. Suele aparecer abajo o arriba a la derecha del navegador.
  3. 🔵 Si sale una pantalla azul, es normal Windows avisa así de cualquier programa que no reconoce todavía. No es un virus. Toca Más información y luego Ejecutar de todas formas.
  4. Se instala solo y el sistema abre. No se pierde nada: las ventas, el turno abierto y la configuración de la caja se quedan tal cual.
